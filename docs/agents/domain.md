# Domain docs

This is a single-context repository.

Before exploring or changing a domain area, read `CONTEXT.md` when it exists
and the relevant decisions under `docs/adr/`. If `CONTEXT.md` is absent,
proceed silently; it is created lazily when domain terminology needs a formal
glossary.

Use canonical Xact vocabulary in issues, tests, hypotheses, and implementation
notes. Do not substitute synonyms for terms defined by the project. Surface
any proposed change that conflicts with an accepted ADR instead of silently
overriding the decision.
